# Repository instructions

Use Chat on Steroids directly for the approved project folder when its app is selected.
Read the relevant source, reproduce defects, implement the requested changes and related tests,
review the complete diff, and run applicable checks before reporting completion.

Keep secrets out of code and logs. Follow GitHub branch protection and required reviews.
Do not force-push, delete branches, or bypass a denied operation.

On resume, inspect the actual files and Git state before continuing. Stop when the requested
work is complete or cancelled; do not invent additional tasks.
